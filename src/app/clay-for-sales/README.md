# Clay for Sales page

Route: `/clay-for-sales` (served from `page.tsx` + `layout.tsx` in this folder, styled by `clay.css`).

Sections are composed in `page.tsx` from components in `src/components/clay/`:

- `ClayNavbar` / `ClayFooter` / `ClayLogoCloud`
- `ClaySalesHero`
- `ClaySalesFeatureCards`
- `ClaySalesPersonalize`
- `ClaySalesAccountSignals`
- `ClaySalesCallAutomation`
- `ClaySalesEnrich`
- `ClaySalesWallOfLove`
- `ClayClosingCta`

Shared types live in `src/types/clay.ts`. Images and videos used on this page are in `public/images/clay/` and `public/videos/clay/`.
